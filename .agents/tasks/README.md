# Tasks

Use `.agents/tasks/` for deferred agent work that should not interrupt the current implementation.

Add a task when:

- a non-blocking issue is discovered during implementation;
- a verification gap needs follow-up work;
- an architecture or content question needs a separate decision;
- a PR review finds a risk outside the current scope.

Keep tasks short, concrete, and linked to the relevant plan, file, or wiki page.
